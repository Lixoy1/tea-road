# Tea Road Web

Первый визуальный frontend-прототип Tea Road.

## Стек
- React
- Vite
- CSS
- lucide-react

## Сейчас реализовано
- Login / Register
- Telegram CTA
- Dashboard
- Investment plans
- Tea Harvest
- Team / referral tree
- Profile
- Wallet
- Deposit
- Withdrawal
- Transaction PIN
- Security
- History
- Responsive mobile layout
- Dark Luxury Emerald / Jade / Gold visual system

## Запуск
```bash
npm install
npm run dev
```

Открыть:
http://localhost:5173

## Важно
Это UI-прототип без backend, реальных платежей и blockchain-подключения.
Следующий слой: API + PostgreSQL + Telegram authentication + admin panel.
